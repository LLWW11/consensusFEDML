## 并行实验启动脚本
- 创建了 `run_fixed_u05_experiments_parallel.ps1`，可并行启动4个固定U=0.5实验
- 四个实验分别分配GPU 0/1/2/3，日志写入 `parallel_logs/` 目录
- 原理：用 `System.Diagnostics.Process` 启动独立进程 + `Start-Job` 异步写日志
- 修复了两轮跨盘复制导致的 PowerShell `@()` 解析失败问题，改用 `New-Object string[]` + 逐条赋值，彻底避开编码/换行符兼容性
- 最终修复：用 Python 以 `utf-8-sig`(BOM) + CRLF 编码写入 PS1 文件，解决 PowerShell 5.1 无 BOM 时解析中文注释失败的问题；脚本改为纯 ASCII 注释
- 放弃 `ProcessStartInfo`+`Start-Job` 方案（Job 跨 runspace 会把 Process 对象序列化为 String），改用 `Start-Process -RedirectStandardOutput/-RedirectStandardError -PassThru` 直接写日志文件
- 自动检测 python：优先用参数指定 → 其次找 conda → 最后用 PATH 中的 python（用户 conda env 已激活时直接走第三条路径）
