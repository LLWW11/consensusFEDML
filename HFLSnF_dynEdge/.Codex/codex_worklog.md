## 2026-07-29：SevereTest 分层实验改用 GPU

### 修改原因

- 分层正式配置和冒烟配置原先明确设置了 `using_gpu: false`，FedML 因而在服务器存在 GPU 时仍选择 CPU。

### 实施内容

- 将 `fedml_config_severe_hfl_30clients_200round.yaml` 和 `fedml_config_severe_hfl_30clients_smoke_2round.yaml` 修改为 `using_gpu: true`、`gpu_id: 0`。
- 在运行入口增加强制 GPU 校验：当 CUDA 不可用、GPU 编号越界或 FedML 实际设备不是 CUDA 时直接报错，禁止静默回退到 CPU。
- 训练启动日志会输出实际 CUDA 设备和显卡名称，便于服务器端确认。
- 更新简体中文说明文档，增加 CUDA 版 PyTorch、可见 GPU 数量和 `CUDA_VISIBLE_DEVICES` 的检查命令。
- 原 10 客户端普通 FedAvg 对照配置保持 CPU 设置不变。

### 验收

- 两份 HFL YAML 均成功解析为 `using_gpu=True`、`gpu_id=0`。
- 单元测试扩展到 13 项并全部通过，新增 CPU 模式、CUDA 缺失报错和合法 CUDA 设备放行测试。
- 本地环境是 CPU 版 PyTorch，因此未在本机执行 GPU 训练；服务器必须安装 CUDA 版 PyTorch，并确保 `torch.cuda.is_available()` 返回 `True`。
