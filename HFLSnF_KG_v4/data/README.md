# V4数据说明

`FB15k-237/`只保存本项目运行必需的三个官方文本划分：

- `train.txt`
- `valid.txt`
- `test.txt`

V4不依赖V3结果目录读取数据。配置中的相对路径 `data/FB15k-237` 会相对于 `HFLSnF_KG_v4/` 解析，因此从IDE或任意终端工作目录启动时都会读取本目录的数据副本。

当前加载器会建立统一实体和关系编号，检查三份数据中的重复及跨划分重叠，并把训练三元组按头实体完整归属划分给37个客户端。

当前可运行的 `balanced_head_entity` 使用头实体互斥和LPT负载均衡；`balanced_head_entity_overlap_target` 在保持头实体互斥、三元组完整和负载合同的前提下搜索目标实体重叠率。数据文件本身不会为重叠率实验复制或改写，只改变训练三元组到客户端的映射。详细定义和校准命令见[重叠率消融实验计划](../重叠率消融实验计划.md)。
