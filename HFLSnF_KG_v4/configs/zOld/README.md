# 历史配置归档说明

本目录保存正式动态拓扑配置确定前产生的35份历史YAML。归档操作只移动文件，没有修改其中的行为参数，因此历史结果仍可通过结果目录中的配置快照审计。

| 子目录 | 数量 | 用途 | 归档原因 |
| --- | ---: | --- | --- |
| `fedadam_stage1/` | 8 | 四套FedAdam学习率与tau组合、HFLSnF/HFLnoSnF的40轮筛选 | 参数筛选已经完成，学习率`0.05`与`tau=0.001`已进入后续实验 |
| `fedadam_stage2_screen/` | 8 | `topology_util=0.5/0.6`、bias correction开关与两臂的150轮全因子筛选 | 全因子筛选和三种子复验已经完成，最终采用`u0p6_bcfalse` |
| `dynamic_alpha0p1_legacy/` | 4 | 早期alpha=0.1动态MAT四实验臂 | 使用旧服务器学习率、利用率与身份字段，不再作为当前主配置 |

合计35份历史YAML。

## V4当前配置与保留结果

当前18份正式配置位于上一级目录，具体说明见[配置文件说明](../README.md)：`dynamic/` 和 `stochastic/` 各9份，均覆盖三个参考臂或预算档位及随机种子42、2024、2025。它们统一采用最终FedAdam训练口径。

V4的 `results/` 当前只保留9个动态三种子结果和6个固定人数随机抽取结果，没有保留随机拓扑、阶段一、阶段二和早期动态实验结果。配置仍然存在不代表相应结果仍保存在V4中。

动态正式配置统一采用：

- `topology_util=0.6`；
- FedAdam学习率`0.05`、`tau=0.001`；
- `server_bias_correction=false`；
- 150轮训练、每轮评估、本地3个epoch。

V4后续重叠率消融固定使用HFLSnF动态正式配置。低、中、高目标重叠配置尚未创建，不能用本目录中的历史YAML替代。

## 复现与兼容性

- 历史运行器和校验器已经同步指向本目录中的对应分类，原有命令仍可用于只读校验或创建新的历史复现批次。
- 归档前生成的阶段一和阶段二`batch_summary.json`绑定了旧配置绝对路径；阶段二还绑定了配置SHA256。文件移动后，不应再使用这些旧清单执行`--resume`，也不应改写清单或绑定哈希。训练结果和结果目录内的配置快照不受影响。
- 使用归档入口新建的批次会记录新路径，并可按各运行器原有规则恢复。
- 归档文件保留原文件名，便于从旧README、日志或结果元数据映射到对应历史配置。
- 历史YAML不得作为当前主实验结果的默认配置引用。
