# V5数据与语义域说明

V5使用本目录中的FB15k-237标准 `train.txt`、`valid.txt` 和 `test.txt`。正式校准合同绑定三份文件的SHA-256，任何内容变化都会使校验失败。

训练关系保留Freebase路径，例如 `/film/...`、`/sports/...` 和 `/location/...`。V5取第一个有效路径分段作为顶级语义域；所有 `/user/...` 关系统一归入 `user`。当前训练集得到30个域。

数据文件本身不会复制、删减或重写。划分器只改变训练三元组到37个客户端的映射，并保证：

- 三元组唯一且完整覆盖；
- 同一语义域和头实体组成的包不可拆分；
- 同一头实体可因不同语义域出现在多个客户端；
- 客户端负载最大相对偏差不超过5%。

FB15k-237不包含真实机构所有权标签，语义域只能作为现实代理，不得称为真实机构划分。具体算法和门禁见[图语义感知划分实验计划](../图语义感知划分实验计划.md)。
